# -SmartBudgetManagger
A project for managing Budget.
Getting started
1. Open SmartBudget_Manager.xlsx in Excel.
2. If Excel displays a security or editing notice, only enable editing if the file comes from a source you
trust.
3. Open the Transactions sheet.
4. Add a new record in the appropriate row. Fill in the fields shown by the column headings, including
the date, description, transaction type, category, and amount where available.
5. Use the categories consistently so that summaries remain meaningful.
6. Open Dashboard to review the latest summary.
7. Save the workbook with Ctrl+S.

Helpful reminders
 Enter amounts as numbers and use the date format expected by the sheet.
 Do not delete or type over cells that contain formulas.
 Check the transaction type and category before moving to the next row.
 If a total or chart does not update, check that the new entry is inside the workbook’s intended data
range.
